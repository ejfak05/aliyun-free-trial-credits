## 哪些情况会扣钱：到期和超额的处理

免费试用不等于三个月随便跑。官方列了四种会产生费用的情形：超出每小时抵扣上限、总额度用尽、3 个月有效期结束，以及使用了不在抵扣范围内的资源（比如某些配套产品或功能）。

最需要盯住的一条：**试用到期后实例不会自动释放**。官方会在到期前通过邮件和站内信发提醒，你需要自己决定续费还是关停。实例放着不管继续跑，就按标准资费计费——不少“免费试用被扣费”的情况都出在这里。

释放实例之后也不能重新再领一次试用，同一类产品的试用权益只有一次。到期后想接着用，就走正常付费，下一节讲怎么选计费方式。

还有几条规则值得知道：试用资源只限本人使用，不能过户转让；禁止用试用机器挖矿，违规会被收费甚至取消试用资格；作弊领取、恶意套现这类行为会被收回权益，严重的会追究责任。

## 常见问题

**个人版和企业版能同时领吗？**

不能。官方明确两版权益不同享，登录后按账号实名认证类型展示对应卡片，以卡片显示为准。

**“立即试用”按钮是灰的，为什么？**

系统判定你不符合试用规则，把鼠标停在按钮上会显示具体原因。常见的有：不是该产品的新用户、账号有欠费、ECS 服务已经开通过。

**试用到期后实例会自动释放吗？**

不会。到期前官方会发邮件和站内信提醒，需要自己选择续费或关停，否则按标准资费计费。

**怎么查剩余额度和到期时间？**

登录费用与成本控制台，点左侧“权益”，按商品名称、试用状态、试用结束时间等条件筛出试用实例，能看到周期内总额、试用进度和超额后的资费规则。

**阿里云国际站也能这么领吗？**

国际站是独立的账号体系和试用政策，和本文说的阿里云中国站不是一回事，资格和额度以国际站页面为准。
